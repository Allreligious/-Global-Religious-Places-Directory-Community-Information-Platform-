# Global Religious Places Directory & Community Information Platform

A global platform connecting people with religious places, spiritual centers, and faith communities worldwide.

Discover places of worship, religious events, cultural activities, and community services while promoting spiritual awareness, cultural diversity, and interfaith understanding.

## Vision

Start in Calgary, Alberta, Canada and grow into a trusted global directory of religious places and community information.

**Calgary → Alberta → Canada → Worldwide**

## Core Features

- Religious place discovery and search
- Religion / faith tradition categories
- Address, phone, email and website
- Interactive map and location information
- Prayer, worship and service times
- Events and community activities
- Photos and organization profiles
- Community services
- Multiple languages
- Organization claim and profile updates
- Verification and change-reporting workflow
- Search-engine friendly public profiles
- Data quality and update timestamps

## Initial MVP

The first release will focus on Calgary.

1. Searchable religious-place directory
2. Individual place profile pages
3. Map-based discovery
4. Organization contact and service information
5. Corrections and update requests
6. A scalable data model for Canada and worldwide

## Planned Technology

- **Frontend:** Next.js + React + TypeScript
- **Database:** PostgreSQL / Supabase
- **Authentication:** Supabase Auth
- **Maps:** OpenStreetMap + Leaflet
- **Hosting:** Vercel
- **Source control:** GitHub
- **Search:** PostgreSQL full-text search initially
- **Automation:** scheduled data-quality checks, update reminders, and verification workflows

## Data Principles

- Accuracy
- Transparency
- Community verification
- Respect for all faith traditions
- Clear source attribution where appropriate
- Privacy and responsible handling of contact information
- No unauthorized copying of protected third-party data
